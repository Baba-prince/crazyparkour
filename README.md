# Crazy Parkour

A browser parkour game with **30 stages**, swimming, kill bricks, spikes, music, and **character customization**.

## Play

Open `index.html` in your browser.

1. Customize your character (body, trim, eyes, hat)
2. Start Stage 1
3. Reach the flag — don’t die!

## Controls

- **Move:** A/D or ← →
- **Jump:** W, Space, or ↑ (hold for higher)
- **Swim (stage 1):** ↑ float, S/↓ dive — dodge bricks & spikes
- **Restart stage:** R
- **Music:** ♪ button

## Difficulty

Same difficulty within each block of 5 stages. New obstacle every stage. Harder every 5 stages.
